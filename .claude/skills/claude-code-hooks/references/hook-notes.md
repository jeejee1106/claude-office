# 훅 확인 기록

`claude-code-hooks` 스킬 2절의 확인 절차로 확인한 사실을 누적한다. 추측은 적지 않는다.

- 문서: https://code.claude.com/docs/en/hooks (2026-10-22 열람)
- 실제 캡처: 2026-10-22, Claude Code **2.1.306**, macOS. `claude -p ... --settings <임시 settings.json> --model haiku` 로 Read → Edit → Bash → 실패하는 Bash(`false`) → Agent(Explore, 안에서 Read·Grep) 를 한 번씩 일으키고, stdin 을 파일로만 저장하는 임시 훅(12개 이벤트 등록)으로 20건을 받았다. 캡처 원본은 저장소 밖 스크래치 경로에 두었고, 민감정보를 지운 사본이 `packages/collector/test/fixtures/` 에 있다.
- 2026-10-23 캡처: Claude Code **2.1.306** 대화형 세션(auto mode), 리더 세션 + 서브에이전트 + 같은 머신의 다른 프로젝트 세션에서 9분간 227건. collector 의 **캡처 모드**(아래)로 키 이름·식별자 앞 4자·열거형만 기록했다. `capture-shape` fixture 는 키 집합만 캡처와 같고 값은 지어낸 것이다.
- **캡처 모드 (디버그 기능, `packages/collector/src/capture.ts`)**: `~/.claude-office/capture` 파일을 만들면 켜진다. 내용이 절대경로면 그 파일, 비어 있으면 `~/.claude-office/hook-capture.jsonl` 에 한 줄씩 덧붙인다. 기록: `ts, hook, keys(최상위 키 이름), session/agent_id(앞 4자), agent_type, notification_type, permission_mode, tool_name, has_tool_use_id`. `tool_input`·`message`·`prompt`·경로 값은 남기지 않는다. 끄려면 플래그 파일을 지운다. `HOME` 이 없으면 꺼진다.
- fixture 의 `_fixture_source` 필드로 출처를 구분한다: `capture …` = 실제 캡처, `docs-derived …` = 문서 예시로 만든 것.
